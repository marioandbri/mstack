# Review agent instructions

Use for a selected AGENTS.md opportunity or a requested whole-file review. Receive the source versions, evidence, accepted decisions and permitted actions from Reflect. This component owns instruction criteria and conducts the scoped interview through the [shared protocol](questionnaire.md).

## Investigate and guide the decision

Identify canonical files, active copies and consumers. Inspect the selected content and relevant surrounding rules. For a whole-file review, read every section and track coverage. A selected opportunity does not require auditing unrelated files.

Separate the decisions or workflow stages combined in an instruction. Check scope, contradictions, duplication and the user's intended behavior. Distinguish cross-task invariants from conditional procedures, project facts and temporary state; request classification when that distinction is uncertain. The current location does not establish ownership.

Inspect existing owners before proposing a new skill. Use [skill support](skill-support.md) for skill content or discovery. Each skill owns its activation conditions; do not add a global selector to compensate for missed invocation. Recommend guidance for a demonstrated decision gap; retaining current behavior remains an option.

Present evidence, consequence, uncertainty, recommendation and one unresolved question. Record the user's experience and decision in the shared review. Keep behavior approval, destination approval and deployment authorization distinct. For an observed agent failure, request [evaluation](failure-evaluation.md) before recommending a behavioral rewrite. State which finding is textual and which has execution evidence.

## Return the candidate

After the relevant decisions and coverage are resolved or explicitly deferred, return the complete requested file, its diff, decision links, validation evidence and remaining gaps. Preserve deferred content and accepted exceptions. For a relocation, include the destination candidate and its discovery or reference checks before presenting source removal as ready.

Check consistency across the whole requested artifact, including untouched content. Recheck source hashes before generating the diff and reopen only decisions affected by drift. For a selected opportunity, identify any unreviewed remainder; do not label it a completed whole-file audit. Return to Reflect for consolidation and authorized integration.
