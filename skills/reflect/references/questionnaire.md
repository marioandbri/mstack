# Guided review

Use this protocol for requested reflection or instruction review. Capture and provisional classification do not start the interview. The active specialist uses this shared protocol within Reflect; keep one active question and one decision record rather than separate interviews.

## Present the opportunity

Inspect the selected instructions and evidence first. Choose an opportunity by its relevance to the user's objective and the strength of its evidence. File length or skill count alone does not justify a change.

Present four things before waiting for an answer:

1. Evidence with its exact source, using a short quotation, observed action or artifact.
2. The possible consequence and what remains uncertain.
3. A recommended behavior and destination, with evidence for each. Inspect existing owners before suggesting another skill.
4. One question about the unresolved behavior, scope, exception or destination. Do not ask again about decisions already made.

Offer choices relevant to that decision. The user can reject the premise, retain the instruction or provide evidence that changes the recommendation. Do not ask for generic approval to clean up a file.

For an observed agent failure, discuss the evaluation case and expected behavior first. Offer bounded preparation and execution when useful, explaining what the result could establish. Compare mitigations after baseline evidence exists. Reuse prior authorization; leave evaluation pending if the user defers it.

A hypothetical question, not an observed incident:

> This instruction requires repairing every failing test encountered, including unrelated ones. It could expand the task. I recommend fixing task regressions and reporting independent failures with an offer to repair them. Would you prefer that boundary or include independent repairs by default?

The example illustrates the question format. Use the actual user's decisions when reviewing their instructions.

## Record the answer

Record the user's answer, scope, rationale and exceptions. Ask a follow-up only when a material distinction remains unresolved. Reuse accepted decisions instead of repeating the questionnaire.

Record approval of behavior separately from approval of its destination when the answer resolves only one. Use the active specialist's criteria for the placement recommendation. Provisional classification and a specialist recommendation are not user decisions. Deployment depends on its own authorization; preserve broader authorization already given. For a new capability, record the user's objective without inventing a historical failure.

## Close or resume

Track every selected source section as reviewed, retained or explicitly deferred. Resolve or explicitly defer each opportunity before producing the final proposal. If the review stops early, save its decisions, coverage and pending question for continuation.

Return the decisions to the active specialist for its artifact checks. For an AGENTS.md candidate, use [instruction review](instruction-review.md) for whole-file consistency, destination changes and the complete diff. Reflect consolidates the result with decision traceability and evaluation status.

If a source changed during the review, reconcile it and reopen only affected decisions before regenerating the proposal.
